valley - clean-room farming game engine

Options:
  --content <dir>     Unpacked game Content folder (or env VALLEY_CONTENT).
                      Without it, the built-in placeholder content is used.
  --saves <dir>       Save folder (default: ~/.local/share/valley-rs/saves).
  --new <name>        Skip the title screen and start a new game.
  --seed <n>          World seed for new games.
  --size WxH          Logical screen size (default 1280x720).
  --mute              Do not open an audio device (or env VALLEY_MUTE=1).
  --headless          Run without a window (uses the software renderer).
  --script "<steps>"  Headless input script, steps separated by spaces:
                        wait:N          advance N ticks (60 per second)
                        hold:KEY:N      hold KEY for N ticks
                        tap:KEY         press KEY for one tick
                        click:X:Y       left click at screen X,Y
                        rclick:X:Y      right click at screen X,Y
                        type:TEXT       type text (use _ for spaces, __ for _)
                        shot:FILE.png   save a screenshot now
                        cmd:COMMAND     run a console command (_ = space,
                                        __ = underscore),
                                        e.g. cmd:mine_3 cmd:give_388_50
  --screenshot <png>  Save a screenshot after the script finishes.

Audio tools (use the --content folder like the game does):
  --audio-info               Show wave/sound banks found and how cues resolve.
  --audio-test [c1,c2,...]   Play cues on the sound device (default: all
                             cues the game uses), to check that sound works.
  --export-cue CUE OUT.wav   Decode one cue or music track to a WAV file.
